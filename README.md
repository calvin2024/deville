# Jon DeVille Campaign Website

This is a **static** website (no build step) designed for **GitHub Pages**.

## What's included
- Modern, responsive campaign design
- Biography, endorsements, testimonials, and letter to residents
- First‑Term Results section with verified accomplishments

## How to preview locally
Just open `index.html` in your browser, or run a simple web server:

```bash
python -m http.server 8000
```

Then browse to: http://localhost:8000

## Quick content edits
All content is in `index.html`.
